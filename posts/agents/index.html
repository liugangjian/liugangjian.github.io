## ANTI-PATTERNS

- **DO NOT** use absolute image paths
- **DO NOT** forget `math: true` for posts with equations
- **AVOID** draft: true for published content

## NOTES

- Images stored in `content/images/`
- Process images with `python process_images.py` for transparency
- Long posts should have `ShowToc: true`
- Use descriptive `description` for SEO
